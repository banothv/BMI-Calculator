# BMI Calculator Website

A simple and user-friendly BMI (Body Mass Index) Calculator website built using Python, Flask, HTML, and CSS.

This project allows users to enter their weight and height to calculate their BMI and view the corresponding BMI category.

## Features

* Calculate Body Mass Index (BMI)
* Enter weight in kilograms (kg)
* Enter height in meters (m)
* Display BMI rounded to two decimal places
* Show BMI category
* Validate positive weight and height values
* Display error messages for invalid numerical input
* Simple and responsive website interface

## Technologies Used

* Python
* Flask
* HTML5
* CSS3

## BMI Categories

| BMI Range        | Category      |
| ---------------- | ------------- |
| Below 18.5       | Underweight   |
| 18.5 to below 25 | Normal Weight |
| 25 to below 30   | Overweight    |
| 30 and above     | Obese         |

## Installation and Setup

### 1. Install Python

Install Python 3 from the official website:

https://www.python.org/downloads/

### 2. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/OIBSIP.git
```

### 3. Open the project folder

```bash
cd OIBSIP/Python-Task2-BMICalculator
```

### 4. Install Flask

```bash
python -m pip install flask
```

### 5. Run the application

```bash
python app.py
```

### 6. Open the website

Open your browser and visit:

<http://127.0.0.1:5000>

## How to Use

1. Open the BMI Calculator website.
2. Enter your weight in kilograms.
3. Enter your height in meters.
4. Click the Calculate BMI button.
5. View your BMI result and category.

## Example

Input:

* Weight: 65 kg
* Height: 1.75 m

Output:

* BMI: 21.22
* Category: Normal Weight
