# BMI Calculator Website

A simple and user-friendly BMI (Body Mass Index) Calculator website built using Python and Flask.

## Features

- Calculate Body Mass Index (BMI)
- Enter weight in kilograms
- Enter height in meters
- Displays BMI result
- Shows BMI category
- Handles invalid input
- Simple and attractive user interface

## BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal Weight |
| 25 - 29.9 | Overweight |
| 30 and above | Obese |

## Technologies Used

- Python
- Flask
- HTML
- CSS
